# Python Logic Journey

Este repositorio contiene una serie de ejercicios organizados por niveles de dificultad, diseñados para fortalecer mi capacidad de resolución de problemas, lógica algorítmica y manipulación de datos con Python.

## Estructura del Proyecto
- `01_Basicos`: Fundamentos de sintaxis, bucles y lógica básica.
- `02_Intermedios`: Estructuras de datos, algoritmos de ordenamiento y manejo de archivos.
- `03_Avanzados`: Matemáticas para ML, POO y procesamiento de datos.

## Objetivo
El objetivo de este proyecto es construir una base sólida para mi carrera en **Machine Learning**, priorizando la eficiencia del código y la comprensión de los fundamentos matemáticos detrás de los algoritmos.
